# Harness Patterns

A plain-English field manual of design patterns for building AI agent harnesses — the agent loop, the tool system, memory and more. Each pattern has a step-by-step explanation, a figure, a code sketch and a note on how large companies use it.

- **Live site (this fork):** https://raghu298.github.io/agent-harness-engineering-pattern-fork/
- **Original site:** https://ashishpatel26.github.io/agent-harness-engineering-pattern/
- **Original repo and author:** [ashishpatel26/agent-harness-engineering-pattern](https://github.com/ashishpatel26/agent-harness-engineering-pattern)

All content is by the original author. This fork adds:

- Page metadata: language tag, description, Open Graph tags, favicon, and `<head>` cleanup
- Light / dark / auto theme button (remembers your choice)
- **Copy** button on every code sketch
- `#` link next to each pattern title that copies a direct link to it
- Back-to-top button
- Print styles (hides the menu and buttons)

## Run locally

It is a single self-contained page — just open `index.html` in a browser.

## Use the page

- Press `/` to search patterns, `Enter` to jump to the first match, `Esc` to clear.
- On a phone, tap **Contents** to open the pattern list.
- Click the moon/sun button at the top right to switch theme.
